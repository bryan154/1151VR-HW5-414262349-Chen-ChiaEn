# 精靈球投擲與噴火龍收服

1151 VR · HW5　陳嘉恩　｜　414262349

![Unity 場景配置](Screenshots/HW5_scene.png)

圖 1　Unity 場景配置。訓練家位於噴火龍左側，後方以樹木與起伏的山稜構成背景。

## 製作流程

1. **建立地形**　在 Unity 6 建立 3D 專案，使用 Terrain 塑造背景山丘、鋪設草地，並在角色後方配置不同高度的樹木。
2. **配置角色**　匯入訓練家、噴火龍與精靈球模型。把訓練家放在鏡頭左側、噴火龍放在右側，再將精靈球放到訓練家手邊作為投擲起點。
3. **編寫投球動作**　將 PokeBallCapture 腳本掛在精靈球上，指定噴火龍為目標。程式在起點與目標之間插值移動，並加上拋物線高度，使球由左向右飛行。
4. **製作收服效果**　球到達噴火龍時，14 個白色光點向外散開，噴火龍同步縮小並消失。最後讓精靈球落在噴火龍原先站立的位置。

## 操作方式

在 Unity 開啟 Assets/Gamescene.unity 並按 Play。電腦版的投球輸入為空白鍵或滑鼠左鍵，手機版的設計為點一下畫面。
